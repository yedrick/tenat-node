# @tenancy-node/orm-mikro-orm

MikroORM integration for tenancy-node (ORM per tenant, forked EntityManager and migrator)

Parte de [tenancy-node](https://github.com/yedrick/tenat-node): multi-tenancy para Node.js con arquitectura hexagonal y observabilidad por tenant.

## Instalación

```sh
npm install @tenancy-node/orm-mikro-orm @tenancy-node/core @tenancy-node/db @mikro-orm/core @mikro-orm/postgresql
```

Requiere Node.js 20 o superior. Funciona con ESM y CommonJS, e incluye los tipos de TypeScript.
