# @tenancy-node/admin-api

Admin REST API for tenancy-node: auth, roles, audit, tenants, SSE progress, data explorer, webhooks, impersonation and OpenAPI

Parte de [tenancy-node](https://github.com/yedrick/tenat-node): multi-tenancy para Node.js con arquitectura hexagonal y observabilidad por tenant.

## Instalación

```sh
npm install @tenancy-node/admin-api @tenancy-node/core @tenancy-node/db @tenancy-node/admin-ui
```

Requiere Node.js 20 o superior. Funciona con ESM y CommonJS, e incluye los tipos de TypeScript.
